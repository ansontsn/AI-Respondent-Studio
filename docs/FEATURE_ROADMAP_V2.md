## 技術限制與測試界線

- V2初次驗收採Mock、HTTP MockTransport、DOM／官方schema樣本及本地Chrome。後續已唯讀解析使用者提供的公開Google正式問卷，仍未測外部多頁填答／提交；真實付費AI作答、Ollama與Google授權測試副本尚未驗證。
- Google 公開 DOM / 公開頁面 metadata 沒有穩定官方契約。僅解析可確認的結構，分流未知不推測；官方 Forms JSON 匯入按官方 schema 實作，授權取回另需權限。
- 未實作 Google OAuth 取回流程、循環 / 向前頁面回跳、特殊題型完整自動辨識或真實市場預測評分。這些功能不標為已完成。
- 人設分布是使用者的情境條件；品質一致性、動機及模型差異不代表對真人的預測準確率。
- 成本預估是啟動前規劃；請求邊界控制無法取代服務商帳戶硬額度，未知 Token / 費用不能當零。
- 條件控制限成年人物及各欄位邊際比例；預算 / 所得、退休 / 年齡可共同檢查，但不能宣稱能自動推理任意生活背景條件。單 worker 依序執行實驗，保持原有持久化恢復方式。
- 動機分類預設為可核對的關鍵詞多標籤；可選 AI 分類。分析方法未以真實受訪者資料驗證。Mock 的情境效果只有有限規則，不等於大型語言模型能力。
- SQLite 升級使用版本化、交易式及可重複執行的加法遷移；升級前建立 SQLite 一致備份，保留原人物、任務與回答。

## 實作紀錄

開發順序依第一階段介面 / 匯入，再第二階段條件 / 比較 / 品質，再第三階段動機 / 情境 / 預算逐步接入；所有新增頁面使用既有 Runtime、Provider、引擎及資料庫。沒有重建專案或改動 ONLYFRAME 網站。

初次交付驗證包含原 61 項測試與 V2 新增 35 項，**96 passed，45.09 秒**；另完成 14 頁真實 Chrome 檢查、4 種分析的三格式匯出及既有資料逐筆比對。原 12 位人物、12 份回答及逐題紀錄保持不變；新增示範 6 位人物、5 組任務、30 份回答。原 V1 ACCEPTANCE 保留原始證據。

同日補上本機 Avast HTTPS 憑證相容處理及分類錯誤訊息；增加 5 項 TLS 測試，最新全套 **101 passed，45.45 秒**。不帶金鑰的官方端點探測確認 HTTPS 驗證可達；未驗證新金鑰認證或付費作答，詳見驗收報告附錄。

各功能修改檔案、新測試、最終測試數量及尚未實測項目列於 [ACCEPTANCE_V2.md](ACCEPTANCE_V2.md)。日常操作見 [README](../README.md)；來源與測試證據保存在 outputs，無需 API Key 即可審閱。
